홈페이지에 보여줄 유튜브 영상

유튜브 영상 주소를 붙여넣으세요 (예: https://youtu.be/… 또는 https://www.youtube.com/watch?v=…). 첫 번째 영상이 크게 나오고, 나머지는 아래 목록으로 나옵니다. 비워두면 채널의 최신 영상 목록이 나옵니다.

영상이 홈페이지에서 재생되지 않을 때
  1. YouTube 스튜디오(studio.youtube.com) → 왼쪽 콘텐츠 → 해당 영상의 세부정보(연필)
  2. 공개 상태가 공개 또는 일부 공개인지 확인 (비공개는 재생 불가)
  3. 아래쪽 자세히 보기 → 퍼가기 허용에 체크 → 저장
  4. 시청자층이 아동용으로 설정된 영상은 일부 기능이 제한될 수 있습니다
