예전 사진 한꺼번에 올리기

  1. 구글 드라이브에서 올릴 폴더(예: 2023 또는 2023/05)를 오른쪽 클릭 → 다운로드 → 받은 압축 파일을 풀어 둡니다.
  2. 아래 폴더 고르기로 그 폴더를 고릅니다. 안에 거래처별 폴더가 있으면 폴더마다 현장 1개(글 1개)로 나누고 폴더 이름을 현장명으로 넣습니다. 폴더가 없으면 사진을 찍은 시간으로 묶습니다.
  3. 묶음마다 분류를 고르고(필수), 필요하면 현장명·사양을 적습니다. 잘못 묶였으면 여기서 나누기 / 위 현장과 합치기로 고칩니다. ★ 대표로를 누르면 그 사진이 대표 사진이 되고, 안 올릴 사진은 빼기를 누릅니다.
  4. 모두 올리기를 누르면 사진을 3:4로 맞추고 가운데에 로고 워터마크를 넣어 순서대로 올립니다. 창을 닫지 마세요. 중간에 끊겨도 다시 폴더를 고르면 이미 올린 묶음은 건너뜁니다.

영상이 홈페이지에서 재생되지 않을 때
  1. YouTube 스튜디오(studio.youtube.com) → 왼쪽 콘텐츠 → 해당 영상의 세부정보(연필)
  2. 공개 상태가 공개 또는 일부 공개인지 확인 (비공개는 재생 불가)
  3. 아래쪽 자세히 보기 → 퍼가기 허용에 체크 → 저장
  4. 시청자층이 아동용으로 설정된 영상은 일부 기능이 제한될 수 있습니다
